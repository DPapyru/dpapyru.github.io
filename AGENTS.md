## Global Rules

- **Comments & Code:** almost never add comments; make the smallest necessary change; reuse existing code.
- **Images / Skills:** only with explicit user authorization.
- **Docs:** no changelogs, no standalone `TODO.md`; plans and progress live in commits, PRs or issues. This repo keeps only `AGENTS.md`, `README.md` and `LICENSE`.
- **Execution Pace:** one step per turn unless the user says otherwise.
- **Commits:** direct to `main` for trivial changes, feature branches for anything larger. Never force-push; never change repository settings.

## Content

- Posts are `src/content/posts/*.md` with `title` and `date` frontmatter; Chinese prose; no HTML embeds.
- Images go to `public/images/` and are referenced by absolute path.
